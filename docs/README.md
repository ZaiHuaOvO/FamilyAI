# Family AI 文档库

本目录保存 Family AI 开发期间的全部文档。原则：**文档只归档、不删除**。已完成或已被替代的文档移入 `00-归档/`，并保留日期与替代关系。

## 目录说明

| 目录 | 内容 |
|---|---|
| `00-归档/` | 原始开发文档、已被替代的旧版文档 |
| `01-项目总览/` | 目标、范围、架构与技术选型 |
| `02-实施阶段/` | 按阶段拆分的实施步骤与验收标准（主要工作文档） |
| `03-设计与规范/` | API 契约、安全规范、开发协作规范 |
| `04-测试与验收/` | 测试清单、验收记录与模板 |
| `05-路线图/` | V1 之后的规划 |
| `06-决策记录/` | 需要用户确认的方案与决策 |

## 当前阶段

见 [进度追踪](进度追踪.md)。

## 文档状态约定

- **草稿**：正在编写，内容可能变动。
- **生效**：当前开发的依据。
- **已完成**：对应阶段已验收。
- **已归档**：不再作为依据，位于 `00-归档/`。

## 更新规则

1. 开始一个阶段前，阅读该阶段文档、前置阶段验收记录与相关规范。
2. 阶段完成后，在 `04-测试与验收/验收记录/` 新增一条验收记录，并更新 [进度追踪](进度追踪.md)。
3. 被替代的文档移入 `00-归档/`，文件名建议为 `YYYY-MM-DD-文档名.md`，不要删除。
4. 文档中不得写入真实 Token、`.env` 内容、聊天记录或家庭私人资料。
5. 文档中的命令与结构必须与实际项目一致；发现不一致时先修正文档再继续开发。
