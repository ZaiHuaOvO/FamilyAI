## 后端测试

```bash
uv run pytest -q
uv run ruff check .
```

真实结果：**153 passed in 2.09s**；`All checks passed!`。

覆盖：

- `FORWARDED_ALLOW_IPS` 拒绝空值、`*`、`0.0.0.0`、局域网地址；环境变量同样校验。
- 回环来源的 `X-Forwarded-For` 生效；非回环来源伪造被忽略。
- 多级 XFF `1.2.3.4, 100.64.1.2` 取最右侧不受信地址 `100.64.1.2`。
- `create_app()` 的代理中间件使用校验后的 `["127.0.0.1", "::1"]`。
- `__main__` 传入 `proxy_headers=False`、`access_log=False`。
- 真实 uvicorn 子进程：`/api/v1/health?query=<marker>` 返回 200，stdout/stderr 不含 marker。
- 应用访问日志不含查询串。

## 真实进程验证

重启 `uv run python -m family_ai_api` 后：

- `http://192.168.5.18:8000/api/v1/health?query=v8logmarker` → 200。
- `http://127.0.0.1:8000/api/v1/health?query=v8logmarker` → 200。
- 终端不再出现 uvicorn 访问日志行；marker 未出现在终端输出。
- 启动日志仍显示 `Uvicorn running on http://0.0.0.0:8000`（过渡期 `.env` 仍为 `0.0.0.0`）。
