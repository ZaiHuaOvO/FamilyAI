## 实施内容

- 新增 `members/store.py`：成员表、Token 哈希、认证、轮换、撤销、bootstrap。
- 新增 `members/cli.py`：create/list/rotate/revoke。
- `security.py`：`require_member` / `require_admin` / `MemberContext`。
- `GET /api/v1/me`。
- 记忆：`visibility`、按 owner 去重与过滤、共享字段、旧库重建迁移。
- 任务：`shared`、owner 过滤、共享字段、旧库迁移。
- 聊天：记忆检索与自动提取绑定成员。
- Agent：工具执行、审计与动作绑定成员；审计仅 admin 可读。
- 请求日志记录 member_id；`/logs` 与 `/agent/audit` 仅 admin。
- 记忆/任务管理页增加共享开关。

## 安全确认

- [x] Token 只存 SHA-256 哈希，未写入 Git/日志/文档。
- [x] 私有数据不能通过列表、搜索、简报或 Agent 工具绕过。
- [x] 共享项仅 owner 可修改/删除。
- [x] 管理员不能通过普通接口读取私有数据。
- [x] `/logs` 与 `/agent/audit` 仅 admin。
- [x] 测试成员已撤销，测试数据已清理。

## 已知限制

- 成员管理仅 CLI，无 HTTP 管理页。
- 撤销成员不删除其数据。
- 只有私有/共享两档可见性，无逐成员 ACL。
- 成员库为单进程 SQLite。
- Token 轮换会使绑定旧 Token 的 Agent 动作失效。
