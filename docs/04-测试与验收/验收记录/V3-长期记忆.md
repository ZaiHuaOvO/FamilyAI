- 新增 `memory/service.py`：内容/标签校验、Embedding、检索上下文。
- 新增 `memory/extractor.py`：严格提示词、JSON 解析、后台自动写入。
- 新增 `routers/memory.py`：CRUD 与管理页面。
- `routers/chat.py`：`use_memory` 开关、记忆注入、后台自动提取。
- `main.py`：自动提取信号量、挂载记忆路由。
- 配置新增记忆与自动提取参数。

## 已知限制

- 自动提取每次聊天会增加一次后台模型调用，可用配置关闭。
- 提取质量依赖模型，可能漏记或措辞不理想。
- 记忆全家共享，暂不区分成员。
- 更换 Embedding 模型后需要重新生成记忆向量。
