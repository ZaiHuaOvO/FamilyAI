## 网络拓扑说明

测试过程中发现 Windows 最初通过网线连接到 `192.168.1.x`（中国电信智能网关 `192.168.1.1`），而 Mac 的 Wi-Fi 来自中兴二级路由器 `192.168.5.1`，两者属于不同子网、互不相通。

最终让 Windows 连接到中兴路由器的 Wi-Fi，获得 `192.168.5.18`，与 Mac 处于同一子网，验证通过。

> V1 不配置跨路由端口转发或二级路由桥接。
