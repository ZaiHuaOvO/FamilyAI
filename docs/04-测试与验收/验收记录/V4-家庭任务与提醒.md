## 已知限制

- 没有主动提醒，需要手动查看。
- 天气需配置经纬度并依赖外部网络。
- 不支持重复任务、子任务、提醒时间或成员分配。
- 页面仅支持编辑标题、完成与删除；到期时间通过 API 修改。
