## 安装过程

- Homebrew 4.4.1 无法识别 macOS 27.0.1，`brew install --cask ollama` 失败。
- 改用官方发布包 `Ollama-darwin.zip`（v0.40.6）。
- GitHub 直连约 39 KB/s，改用 `gh-proxy.com` 镜像（约 18 MB/s），并使用官方 `sha256sum.txt` 校验，SHA256 一致。
- 安装到 `/Applications/Ollama.app`，清除 quarantine，CLI 软链到 `~/.local/bin/ollama`。
- 模型通过 `ollama pull qwen3.5:4b` 下载，Ollama 自身多连接下载，约 2.2 MB/s。
