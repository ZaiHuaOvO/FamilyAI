## 实施内容

- `agent/registry.py`：7 个白名单工具、参数校验、执行与结果序列化。
- `agent/planner.py`：规划提示词、JSON 解析、日期防幻觉、回答生成。
- `agent/actions.py`：pending action、Token 绑定、单次使用、TTL。
- `agent/audit.py`：内存审计。
- `routers/agent.py`：Agent API。
- `main.py`：初始化动作/审计存储并挂载路由。
- 配置新增 Agent 开关、写工具开关、结果长度、动作 TTL、审计容量。

## 端到端验证

| 检查 | 结果 |
|---|---|
| `GET /agent/tools` | 7 个工具；3 个写工具 |
| 无工具请求 | 直接回答，`tool=null` |
| `list_tasks` | 工具调用成功，回答无待处理任务 |
| `search_knowledge` | 正确回答默认模型 `qwen3.5:4b` |

| 审计 | 工具名/状态/耗时/动作 id；无参数内容 |
| 日志 | 不含 Agent 消息内容 |

## 已知限制

- 规划器可能选错工具或输出无法解析的 JSON；无效计划退化为普通回答。
- pending action 与审计在内存中，重启清空。
- Agent 聊天暂不支持流式、历史消息或记忆自动注入。
- 每次 Agent 请求通常需要两次模型调用。
- 写操作执行失败后需重新规划。
