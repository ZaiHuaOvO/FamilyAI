> 状态：**生效**  
> 使用方式：每个阶段完成时逐项检查；未通过项必须记录原因，不得勾选。

## 1. 功能

- [x] `ollama --version` 正常。
- [x] `ollama list` 能看到使用的模型。
- [x] Ollama 本机多轮对话正常。
- [x] Ollama HTTP API `/api/tags` 返回模型列表。
- [x] Ollama HTTP API `/api/chat` 返回真实回答。
- [x] FastAPI 服务可启动。
- [x] `GET /api/v1/health` 返回 `{"status":"ok"}`，不泄露配置。
- [x] `GET /api/v1/models` 需要 Token，只返回配置允许的模型。
- [x] `POST /api/v1/chat` 调用 Ollama 并返回真实回答。
- [x] 响应中的 `model`、`duration_ms` 为真实值。
- [x] 模型名称来自配置，客户端不能指定。

## 2. 安全

- [x] 无 Token 请求聊天接口返回 401，且未调用模型。
- [x] 错误 Token 返回 401。
- [x] Token 比较使用常量时间方式。
- [x] 空消息、仅空格消息被拒绝。
- [x] 超长消息被拒绝。
- [x] 非法 JSON / 错误类型被拒绝。
- [x] 请求体过大被拒绝。
- [x] 并发上限生效（单元测试覆盖，超出返回 429）。
- [x] 基础限流生效（单元测试覆盖，超出返回 429）。
- [x] 上游超时返回 504（单元测试覆盖）。
- [x] Ollama 不可达返回 503（实测 78ms）。
- [x] 配置模型不存在返回 502（实测）。
- [x] 错误响应不含堆栈、路径、Token、环境变量。
- [x] 日志不含 Token。
- [x] 日志不含完整聊天正文。
- [x] `.env` 被 `.gitignore` 忽略。
- [x] Git 历史中没有真实密钥。
- [x] Ollama 只监听 `127.0.0.1:11434`。
- [ ] FastAPI 是家庭局域网唯一入口（待阶段5验证）。
- [ ] 路由器没有到公网的端口映射（未检查路由器；本项目未做任何端口映射操作）。
- [x] 未引入 Shell 执行、任意文件读写、智能家居控制。
- [x] 本机 Ollama 请求使用 `trust_env=False`，不受系统代理影响。
