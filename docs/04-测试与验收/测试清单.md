# V1 测试清单

> 状态：**生效**  
> 使用方式：每个阶段完成时逐项检查；未通过项必须记录原因，不得勾选。

## 1. 功能

- [ ] `ollama --version` 正常。
- [ ] `ollama list` 能看到使用的模型。
- [ ] Ollama 本机多轮对话正常。
- [ ] Ollama HTTP API `/api/tags` 返回模型列表。
- [ ] Ollama HTTP API `/api/chat` 返回真实回答。
- [ ] FastAPI 服务可启动。
- [ ] `GET /api/v1/health` 返回 `{"status":"ok"}`，不泄露配置。
- [ ] `GET /api/v1/models` 需要 Token，只返回配置允许的模型。
- [ ] `POST /api/v1/chat` 调用 Ollama 并返回真实回答。
- [ ] 响应中的 `model`、`duration_ms` 为真实值。
- [ ] 模型名称来自配置，客户端不能指定。

## 2. 安全

- [ ] 无 Token 请求聊天接口返回 401，且未调用模型。
- [ ] 错误 Token 返回 401。
- [ ] Token 比较使用常量时间方式。
- [ ] 空消息、仅空格消息被拒绝。
- [ ] 超长消息被拒绝。
- [ ] 非法 JSON / 错误类型被拒绝。
- [ ] 请求体过大被拒绝。
- [ ] 并发上限生效（超出返回 429）。
- [ ] 基础限流生效（超出返回 429）。
- [ ] 上游超时返回 504，不无限等待。
- [ ] Ollama 不可达返回 503。
- [ ] 配置模型不存在返回 502。
- [ ] 错误响应不含堆栈、路径、Token、环境变量。
- [ ] 日志不含 Token。
- [ ] 日志不含完整聊天正文。
- [ ] `.env` 被 `.gitignore` 忽略。
- [ ] Git 历史中没有真实密钥。
- [ ] Ollama 只监听 `127.0.0.1:11434`。
- [ ] FastAPI 是家庭局域网唯一入口。
- [ ] 路由器没有到公网的端口映射。
- [ ] 未引入 Shell 执行、任意文件读写、智能家居控制。

## 3. 稳定性

- [ ] `uv run pytest` 全部通过。
- [ ] `uv run ruff check .` 通过。
- [ ] 连续 20 条请求没有令服务崩溃。
- [ ] 两条并发请求行为符合预期。
- [ ] Ollama 停止时 FastAPI 有限时间内返回错误。
- [ ] Ollama 重启后聊天恢复。
- [ ] FastAPI 重启后服务恢复。
- [ ] 已记录 M3 16GB 下的性能基线。
- [ ] 已确认锁屏、显示器关闭、合盖/睡眠对服务的影响。

## 4. 局域网与部署

- [ ] FastAPI 绑定 `0.0.0.0` 后，另一台局域网设备可访问健康检查。
- [ ] 另一台设备可带 Token 调用聊天。
- [ ] 另一台设备无 Token 调用失败。
- [ ] Ollama 端口在局域网不可访问。
- [ ] macOS 防火墙保持开启。
- [ ] 未配置公网端口映射。

## 5. 文档与发布

- [ ] README 与实际启动方式一致。
- [ ] API 文档（`/docs`）与实际接口一致。
- [ ] `docs/进度追踪.md` 已更新。
- [ ] 各阶段验收记录已归档。
- [ ] 原始开发文档保留在 `docs/00-归档/`。
- [ ] V1 完成定义全部满足。
- [ ] 已打 `v1.0.0` 标签。
