## 高严重度问题与修复

1. **APP_HOST / APP_PORT 未被读取**
   - 文档承诺 `.env` 控制监听地址与回退，但原代码只由 `uvicorn --host` 决定。
   - 修复：新增 `src/family_ai_api/__main__.py`，通过 `uvicorn.run` 读取 `settings.app_host/app_port`；README、阶段5、阶段6、技术架构改用 `uv run python -m family_ai_api`，并说明命令行参数会覆盖 `.env`。

2. **chunked 请求体可绕过 16KB 上限**
   - 原实现只检查 `Content-Length`。
   - 修复：新增 ASGI `BodySizeLimitMiddleware`，在 receive 层累计实际字节；超限时返回 413。新增 chunked 回归测试。

3. **空天气配置导致启动失败**
   - `.env.example` 的空 `WEATHER_LATITUDE/LONGITUDE` 被 Pydantic 当作非法 float。
   - 修复：`Settings` 增加 before validator，把空白字符串归一为 `None`；新增配置测试。
