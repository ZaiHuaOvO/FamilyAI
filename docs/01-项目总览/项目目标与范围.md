# 项目目标与范围

## 1. 项目背景

Family AI 的目标是让家里的 MacBook Pro（M3 / 16GB）承担一个私有、可控的本地 AI 后端，先服务自己与家人，再把能力逐步扩展到家中的其他设备。

V1 只解决一个问题：**让 Mac 稳定地运行本地模型，并通过一个受控 API 提供服务。**

## 2. V1 要实现

- Mac 本机可以运行一个本地开源大模型并与之多轮聊天。
- 可以通过 HTTP API 调用本机模型。
- FastAPI 提供的聊天能力必须校验访问令牌。
- 同一家庭局域网内的设备可以调用 FastAPI。
- Ollama 原始端口（11434）继续只监听本机，不向局域网暴露。
- 具备基础测试、日志、错误处理与 README。

## 3. V1 明确不做

- iOS / macOS 客户端。
- 长期记忆、RAG、向量数据库。
- 自动读取聊天记录、照片、邮件或整个电脑文件夹。
- 日历、天气、收衣服提醒等主动任务。
- 自动执行 Shell、控制家庭设备或修改文件。
- 公网直接开放 API。
- 微调或重新训练模型。
- 流式输出（留到 V1.1，先保证非流式链路稳定）。

## 4. V1 完成定义

以下条件全部满足才视为 V1 完成：

- [ ] Mac 能稳定运行一个本地模型。
- [ ] `curl` 可以直接调用 Ollama 本机 API。
- [ ] FastAPI 提供健康检查、模型信息和聊天接口。
- [ ] 聊天 API 使用 Token 认证、输入校验、超时与并发保护。
- [ ] 家庭局域网另一台设备可以带 Token 调用 FastAPI。
- [ ] Ollama 原始端口未开放给局域网或公网。
- [ ] Token、家庭私人资料或聊天内容未提交到 Git。
- [ ] 基础测试、静态检查和性能记录已完成。

## 5. 约束与前提

| 约束 | 说明 |
|---|---|
| 硬件 | MacBook Pro M3，统一内存 16GB，需为模型预留 20～30GB 磁盘 |
| 网络 | 只在家用 Wi-Fi 内提供服务；不做端口映射 |
| 安全 | 局域网不等于可信网络，所有聊天请求必须认证 |
| 开发方式 | AI Agent 分阶段实现，人工负责架构、行为、安全与验收 |
| 语言 | 后端使用 Python；AI 相关生态（Ollama、RAG、Embedding）集中在 Python |
| 运行方式 | 先手动启动；稳定后再考虑登录自启动 |

## 6. 成功标准

- 家人设备可以稳定完成“提问 → 得到本地模型回答”的完整链路。
- 关闭 Ollama、模型错误、超时等异常都能在有限时间内得到明确错误，而不是无限等待或崩溃。
- 服务的行为、配置、限制与已知风险有文档可查，后续阶段可以平滑扩展。
- 安全边界清晰：局域网唯一入口是 FastAPI，Ollama 不对外，密钥不进仓库。
