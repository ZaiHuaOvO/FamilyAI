# V8 决策记录：外部访问方案

- 日期：2026-11-24
- 状态：已采纳 Tailscale Serve；绑定地址与账号结构待用户确认
- 相关：[V8 阶段文档](../02-实施阶段/V8-外部访问.md) · [运维手册](../03-设计与规范/V8-外部访问运维手册.md)

## 背景

Family AI 目前只服务家庭局域网：iOS 客户端通过 `http://<lan-ip>:8000` 访问 FastAPI，FastAPI 再调用仅监听 `127.0.0.1` 的 Ollama。V7 已完成客户端与 Keychain 验证。

安全规范明确：

- 不开放公网、不做路由器端口映射或 DMZ。
- FastAPI 是唯一入口，所有聊天请求必须验证 Token。
- 需要外网访问时，先评估 Tailscale 等私有网络，并设计设备管理与密钥轮换。

## 决策

1. **只使用 Tailscale Serve**，仅 tailnet 内可达；**禁止 Tailscale Funnel**。
2. **不使用** ngrok、Cloudflare Tunnel 等公网 URL 方案，也不做路由器端口映射。
3. 保留 Bearer Token 作为唯一应用层鉴权；不信任 Tailscale 身份头。
4. V8 目标把 FastAPI 绑定改为 `127.0.0.1:8000`，让 Serve 成为唯一入口；过渡期不改现有 `.env`，待 Serve 验证后再迁移。
5. 代理信任只允许回环地址；`FORWARDED_ALLOW_IPS=*` 或非回环值会导致启动失败。
6. 关闭 uvicorn 访问日志，应用日志只记录 path；查询串、Token、Authorization、正文不落盘。
7. 成员管理沿用现有 CLI：create/list/rotate/revoke；推荐“一人一 Token”，设备撤销交给 Tailscale。
8. V8 不新增 HTTP 接口、不改数据库结构、不加多进程、不集成 Tailscale API。

## 备选方案

| 方案 | 暴露面 | 结论 |
|---|---|---|
| Tailscale Serve | 仅 tailnet，HTTPS | **采用**：免费、无端口映射、证书受 iOS 信任、ACL/设备管理完善 |
| Tailscale Funnel | 公网 URL | **禁止**：无逐请求认证，违反“不开放公网裸 API” |
| Cloudflare Tunnel + Access | 公网 URL，Access 保护 | 备选：需自有域名；原生 App 需 service token；边缘可见明文 |
| 纯 WireGuard + DDNS | 公网 UDP 端点 | 不采用：需路由器端口映射，违反安全规范 |
| ngrok | 公网 URL | 不采用：仅适合临时测试，免费版有 interstitial |
| Twingate | 私有 overlay | 备选：Connector 官方不支持 macOS 原生，单 Mac 场景需 Docker/VM |
| ZeroTier | 私有二层网络 | 备选：无内置 HTTPS 证书与身份头，需自建 |

## 为什么不是 Funnel

Funnel 会把服务暴露到整个公网，不附加逐请求认证；任何拿到 `ts.net` URL 的人都能尝试访问。虽然本服务有 Bearer Token，但这与“不开放公网裸 API、不做公网暴露”的项目底线冲突，也会引入扫描、暴力尝试与额度风险。若未来确实需要公网访问，必须另立阶段、单独审批并设计额外认证。

## 后果

正面：

- 无公网 IP、无路由器改动，外出可用。
- TLS 证书由 Tailscale 自动签发，iOS ATS 无需例外。
- 设备级 ACL、设备移除、密钥过期与成员 Token 轮换可组合使用。

代价与风险：

- 每台设备需安装并登录 Tailscale；iOS 同一时间只能启用一个 VPN。
- Mac 睡眠/合盖后服务离线；需要接电源 + 开盖。
- 依赖 Tailscale 控制面与 DERP 中继；元数据对 Tailscale 可见。
- 保留 `0.0.0.0` 时局域网明文旁路仍存在；迁移到 `127.0.0.1` 后家庭设备也需经 Tailscale。
- Serve 的 Host/X-Forwarded-For 行为需实测；未实测前不启用 `TrustedHostMiddleware`、不按 IP 限流。
