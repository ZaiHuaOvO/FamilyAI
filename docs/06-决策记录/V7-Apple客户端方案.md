# V7 Apple 客户端方案决策

> 状态：**待用户决定（2026-11-24）**  
> 前置：V6 已完成（`v6.0.0`）  
> 目的：在开始 Apple 客户端前，明确平台、首版范围、Token 存储与通知方案。

## 1. 目标

为家庭局域网内的 Family AI 提供原生 Apple 客户端，便于日常使用。

- iPhone / iPad 上聊天、查看流式输出与历史。
- Token 安全存储，不写入源码、日志或 iCloud 明文。
- 可选：记忆、任务、知识库页面；Widget；通知。

## 2. 平台选项

| 方案 | 说明 | 优点 | 成本 | 建议 |
|---|---|---|---|---|
| **A. iOS/iPadOS SwiftUI（推荐首版）** | 单一 iOS 工程，适配 iPhone/iPad | 覆盖主要使用场景；开发量可控 | 需要 Xcode、签名与真机测试 | **推荐** |
| B. macOS 菜单栏 App | 常驻菜单栏，快速聊天/简报 | 与 Mac 服务器同机，通知方便 | 需要单独 macOS 工程 | 后续 |
| C. Universal SwiftUI | iOS + macOS 共用大部分代码 | 一次覆盖两端 | 工程配置、适配更多 | 后续 |
| D. PWA / Web | Safari 添加到主屏幕 | 无 App Store、跨平台 | 无 Widget、后台推送受限 | 备选 |

## 3. 首版功能选项

| 范围 | 内容 | 建议 |
|---|---|---|
| **A. 聊天核心（推荐）** | Token 配置、健康检查、非流式/流式聊天、历史、连接错误处理 | **首版** |
| B. 家庭数据 | 记忆列表/共享、任务/简报、知识库问答 | 第二阶段 |
| C. Widget/通知 | 主屏 Widget、每日简报通知 | 后续 |
| D. 全量 | 以上全部 | 不建议一次完成 |

## 4. Token 与网络

- Token 只存 **Keychain**，不写 UserDefaults、日志或源码。
- 每个成员使用自己的 Token；客户端不共享 Token。
- 局域网地址可配置（如 `http://192.168.5.18:8000`），并处理 IP 变化。
- iOS 需要“本地网络”权限；HTTP 明文访问局域网需要在 Info.plist 配置 ATS 例外（仅本地地址）。
- 不对外开放公网；外出访问后续评估 Tailscale。
- Token 轮换/撤销后，客户端应清除本地 Token 并提示重新配置。

## 5. 通知选项

| 方案 | 说明 | 建议 |
|---|---|---|
| **A. 首版无通知** | 只做应用内体验 | **推荐** |
| B. 本地通知 | App 内定时/打开时提醒 | 第二阶段 |
| C. APNs 推送 | 需要服务端证书/推送服务，且服务端目前不外网 | 后续评估 |

## 6. 测试与交付

- 需要 Xcode、iOS Simulator；真机测试需要开发者签名。
- 首版验收：配置 Token → 健康检查 → 流式聊天 → 历史 → 错误提示。
- 不把 Token、聊天记录写入日志或截图。
- 客户端代码与后端同仓库或独立仓库需用户决定。

## 7. 需要用户决定的事项

1. **首个平台**：iOS/iPadOS SwiftUI / macOS 菜单栏 / Universal / PWA。
2. **首版范围**：聊天核心 / 再加家庭数据 / 再加 Widget 与通知。
3. **通知**：首版无通知 / 本地通知 / APNs。
4. **仓库**：客户端放在当前 FamilyAI 仓库 / 独立仓库。

推荐：**iOS/iPadOS SwiftUI + 聊天核心 + 首版无通知 + 独立 `family-ai-ios` 目录或仓库**。
