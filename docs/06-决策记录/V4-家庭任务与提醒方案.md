# V4 家庭任务与提醒方案决策

> 状态：**待用户决定（2026-10-18）**  
> 前置：V3 已完成（`v3.0.0`）  
> 目的：在实现任务/提醒前，明确数据来源、通知方式与打扰边界。

## 1. 目标

帮助家庭管理任务与提醒，例如“周五提醒交水电费”“周末带孩子去公园”。

原则：

- 主动通知必须可关闭，默认不应频繁打扰。
- 只读取用户明确授权的数据。
- 任务与提醒数据保存在本机，不进入 Git 或日志。
- 没有客户端 App 之前，优先提供 API 与网页，不急于做推送。

## 2. 功能范围选项

| 方案 | 内容 | 优点 | 风险/成本 | 建议 |
|---|---|---|---|---|
| **A. 本地任务 + 按需简报（推荐）** | SQLite 任务 CRUD、到期查询、每日简报页面/API | 依赖少、隐私风险低、可快速验收 | 不会主动提醒 | **推荐** |
| B. 加入天气 | 在简报中加入天气（Open-Meteo，无需 API Key） | 简报更实用 | 需要联网与地点配置 | 可选 |
| C. 加入 Apple 日历 | 通过 AppleScript/JXA 读取 Calendar.app | 与现有日程联动 | 需要自动化权限；日历含敏感信息；实现脆弱 | 后续评估 |
| D. 暂缓 V4 | 保持 V3 | 无新增复杂度 | 无任务/提醒 | 视需求 |

## 3. 通知方式选项

| 方式 | 说明 | 优点 | 代价 |
|---|---|---|---|
| **A. 仅 API/页面（推荐首版）** | 用户主动打开页面或调用接口查看 | 无打扰、无额外权限 | 不会主动提醒 |
| B. macOS 本地通知 | `osascript display notification` | 无需外部账号，适合当前 Mac 服务器 | 需要调度器与通知权限；用户可能错过 |
| C. 邮件 | SMTP 发送 | 跨设备 | 需要邮箱凭据；隐私与配置成本高 |
| D. 手机推送 | 需要客户端/推送服务 | 体验最好 | V7 客户端阶段再做 |

## 4. 建议的首版（A + 仅 API/页面）

### 4.1 数据模型

SQLite `data/tasks.db`：

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `title` | 任务标题 |
| `notes` | 备注（可选） |
| `due_at` | 到期时间（ISO 8601，可选） |
| `done` | 是否完成 |
| `created_at` / `updated_at` | 时间戳 |
| `owner` | 预留家庭成员字段，默认 `shared` |

### 4.2 接口

| 方法 | 路径 | 说明 | 认证 |
|---|---|---|---|
| `POST` | `/api/v1/tasks` | 新建任务 | 是 |
| `GET` | `/api/v1/tasks` | 列表/按到期筛选 | 是 |
| `PATCH` | `/api/v1/tasks/{id}` | 修改/标记完成 | 是 |
| `DELETE` | `/api/v1/tasks/{id}` | 删除 | 是 |
| `GET` | `/api/v1/tasks/view` | 任务管理页面 | 页面可访问，数据需 Token |
| `GET` | `/api/v1/briefing` | 今日/逾期任务简报（可选天气） | 是 |

### 4.3 安全与隐私

- 所有任务数据接口需要 Token；页面不嵌入数据。
- `data/tasks.db` 不提交 Git。
- 日志不记录任务标题、备注或简报内容。
- 不自动读取日历、邮件或通讯录。
- 主动通知默认关闭；启用必须有明确配置与暂停方式。
- 时间使用本地时区展示，存储使用带时区的 ISO 8601。

### 4.4 测试

- 任务 CRUD、到期筛选、完成状态、参数校验。
- 简报只包含到期/逾期任务；无任务时返回空列表。
- 认证、日志脱敏、页面加载。
- 真实测试：创建任务、查询今日任务、标记完成、删除。

## 5. 后续可评估

- 天气：Open-Meteo + 城市/经纬度配置。
- Apple 日历只读同步：需要自动化权限与明确的日历选择。
- macOS 通知：配合 launchd 每日定时触发。
- 手机推送：与 V7 客户端一起设计。

## 6. 需要用户决定的事项

1. **V4 范围**：仅本地任务 / 任务 + 天气 / 任务 + Apple 日历 / 暂缓。
2. **通知方式**：仅 API/页面 / macOS 本地通知 / 邮件 / 暂不通知。
3. **如果加入天气**：使用哪个城市或经纬度（只需大致位置）。
4. **是否需要定时简报**：手动查看 / 每天固定时间（需要 launchd 或调度器）。

推荐：**本地任务 + 可选天气 + 仅 API/页面 + 手动简报**；日历、邮件与自动通知留到后续。
