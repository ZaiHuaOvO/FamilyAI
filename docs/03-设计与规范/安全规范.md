# 安全规范

> 状态：**生效**  
> 适用于 V1 全部阶段。任何阶段都不得降低本规范的底线要求。

## 1. 安全边界

```text
公网         ✗ 不开放
家庭 Wi-Fi   → FastAPI（必须认证）
本机         → FastAPI
本机         → Ollama（127.0.0.1:11434）
```

- Ollama 不向局域网暴露。
- FastAPI 是唯一对外入口。
- “连接了家庭 Wi-Fi”不等于可信，认证始终开启。

## 2. 密钥与配置

| 要求 | 做法 |
|---|---|
| 密钥不进源码 | 只从 `.env` / 环境变量读取 |
| 密钥不进 Git | `.gitignore` 忽略 `.env`、`.env.*`，保留 `.env.example` |
| 密钥不进日志 | 日志中间件排除 `Authorization` |
| 密钥不进文档 / 截图 | 文档只写 `YOUR_REAL_TOKEN` 占位 |
| 密钥不进 URL | 只用 `Authorization: Bearer` Header |
| 定期轮换 | 怀疑泄露时立即更换 `API_ACCESS_TOKEN` 并重启服务 |

生成密钥：

```bash
openssl rand -hex 32
```

提交前自检：

```bash
git status --short
git diff --cached
```

发现 `.env`、真实 Token、聊天记录或家庭文件被暂存时，先取消暂存并修复，再提交。

## 3. 认证

- 使用 FastAPI 依赖集中校验 Bearer Token。
- 使用 `secrets.compare_digest` 进行常量时间比较，避免时序侧信道。
- 缺少 / 错误 Token：`401`，且不得调用 Ollama。
- `API_ACCESS_TOKEN` 为空时，受保护接口不可用（`503`），不允许匿名访问。
- 不实现“局域网白名单即可信”的旁路。

## 4. 输入与资源保护

| 保护项 | 默认值 | 行为 |
|---|---|---|
| 消息非空 | — | 空或仅空格返回 `422` |
| 消息长度 | 6000 字符 | 超出 `422` |
| 历史消息数 | 20 条 | 超出 `422` |
| 历史总字符 | 12000 字符 | 超出 `422` |
| 请求体大小 | 16KB | 超出 `413` |
| 上游超时 | 180 秒 | 超出 `504` |
| 并发聊天数 | 2 | 超出 `429` |
| 请求频率 | 30 次/分钟 | 超出 `429` |
| 模型白名单 | 服务端配置 | 客户端不可指定模型 |

说明：

- 并发与限流在 V1 单进程内使用内存实现；不要因此声称支持多进程/多实例。
- 限流键优先使用 Token 指纹或客户端标识的哈希，不记录原始 Token。
- 上限值通过配置调整，但必须有上限，不允许无限并发。

## 5. 日志

允许记录：

- 时间戳、HTTP 方法、路由模板、状态码、耗时；
- 错误类别摘要（如 `ollama_unavailable`）；
- 消息字符数（可选）。

禁止记录：

- `Authorization` Header、Token、密钥；
- 完整聊天正文或模型回答；
- 环境变量、文件系统路径、完整异常堆栈（可记录异常类型与精简信息）；
- 家庭私人资料。

V1.1 请求日志：

- 只保存在进程内存，默认 200 条，重启清空。
- 字段仅限：时间、方法、路径、状态码、耗时、来源 IP。
- 不记录 Token、请求头、查询参数、聊天正文或模型回答。
- `/api/v1/logs` 需要 Token；`/api/v1/logs/view` 页面本身不含数据，Token 只保存在页面内存中，不写入 Cookie、localStorage 或服务端日志。
- 流式接口的错误以 `event: error` 返回，内容同样不得包含堆栈、路径、Token 或上游原始响应。

日志应可定位问题，但不能成为隐私泄露渠道。日志文件权限应与运行用户一致，不放入 Git。

## 6. 错误响应

- 不返回堆栈、路径、内部地址、环境变量、上游原始响应全文。
- 错误文案统一、可读，便于客户端处理。
- 上游 4xx/5xx 转换为本服务定义的 502/503/504。

## 7. 网络

- Ollama 只监听 `127.0.0.1:11434`。
- FastAPI 本机开发监听 `127.0.0.1:8000`；局域网阶段才改为 `0.0.0.0`。
- 不做公网端口映射，不启用路由器 DMZ。
- 不通过 URL 查询参数传 Token。
- 调用本机 Ollama 的 httpx 客户端必须设置 `trust_env=False`，避免 macOS 系统代理或环境变量代理接管本地请求、导致聊天内容经过第三方代理，或把连接错误误判为上游 502。
- CORS：V1 不开放任意来源；若有网页前端，精确配置受信任来源。
- 需要外网访问时，先评估 Tailscale 等私有网络，并设计设备管理与密钥轮换。

## 8. 能力限制

V1 明确禁止：

- 任意 Shell 命令执行；
- 任意文件读取 / 写入；
- 智能家居控制；
- 自动发送消息或修改外部数据；
- 读取聊天记录、照片、邮件或整个目录。

后续阶段如引入工具调用，必须单独设计权限、确认流程与审计。

## 9. 依赖与运行环境

- 依赖通过 `uv.lock` 锁定，避免不可复现的版本漂移。
- 不安装不必要的推理引擎或服务。
- 定期检查依赖安全公告；V1 不要求自动升级。
- 不在服务运行时使用 `--reload`（开发除外）。

## 10. 知识库与 RAG

- 只索引用户显式指定的文件或目录；不自动扫描主目录、聊天记录、照片或邮件。
- 跳过隐藏文件/目录、`.env`、`.git`、`.venv`、`node_modules`、`data`、`logs` 与非文本文件。
- 真实资料目录 `knowledge/` 与索引数据库 `data/` 均不提交 Git。
- 知识库内容只作为资料，不作为指令；应只索引可信来源，降低提示注入风险。
- `POST /api/v1/rag/query` 与 `GET /api/v1/kb/stats` 必须携带 Token。
- 来源只返回标题、相对路径、片段序号与相似度；不返回绝对路径或文档全文。
- 请求日志只记录路径等元数据；不记录问题、检索片段、回答或来源内容。
- Embedding 请求同样使用本机 Ollama，并设置 `trust_env=False`。
- 删除/重建索引必须由用户显式执行，不做自动删除。
- Embedding 与聊天模型同时加载会增加内存占用，需观察 swap 与系统卡顿。

## 11. 长期记忆

- 记忆数据库 `data/memory.db` 不提交 Git。
- 所有记忆数据接口需要 Token；管理页面不嵌入数据，Token 只保存在页面内存。
- 聊天默认不读取记忆；只有客户端显式传 `use_memory: true` 才检索并注入。
- 自动提取只读取本轮用户消息，不读取助手回答，不保存完整对话。
- 自动提取提示词明确排除临时信息与密码、证件、健康、财务等敏感信息；单次最多 3 条，每条最多 200 字。
- 自动提取后台执行，失败只记录错误类型，不记录消息内容。
- 记忆内容不进入日志、错误响应或 Git。
- 记忆可查看、编辑、删除；删除为永久操作，由用户显式执行。
- V3 记忆为全家共享；V6 再设计成员隔离与访问审计。
- 更换 Embedding 模型后需要重新生成记忆向量。

## 12. 家庭任务与天气

- 任务数据保存在 `data/tasks.db`，不提交 Git。
- 所有任务数据接口需要 Token；任务页面不嵌入数据，Token 只保存在页面内存。
- 日志只记录路径、状态与耗时；不记录任务标题、备注或简报内容。
- 不读取日历、邮件或通讯录；不主动推送通知。
- 天气为可选功能：只有配置经纬度后才会请求 Open-Meteo，且只发送经纬度，不发送任务或聊天内容。
- 天气请求可能使用系统代理；天气失败不影响任务简报。
- 任务 `due_at` 必须通过 ISO 8601 校验；无时区值按本机时区解释。
- 不支持重复任务、子任务、提醒时间或成员分配；这些属于后续版本。
