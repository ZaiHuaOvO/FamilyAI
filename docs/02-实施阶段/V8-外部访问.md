## 1. 目标

在不开放公网、不做路由器端口映射的前提下，让家庭成员离开家庭 Wi-Fi 后仍能安全使用 Family AI：

- 只通过 **Tailscale Serve** 提供 tailnet 内 HTTPS 入口。
- 明确 **禁止 Tailscale Funnel**、ngrok、Cloudflare 公网隧道等公网暴露方式。
- 保留 FastAPI Bearer Token 认证作为唯一应用层鉴权，不新增“来自 tailnet 即可信”的旁路。
- 完成设备与密钥管理：Tailscale 设备可移除，成员 Token 可轮换/撤销。
- 现有局域网使用在过渡期不回归。

非目标：

- 不新增 HTTP 接口、不改数据库结构、不增加 Web 设备管理页、不集成 Tailscale API。
- 不引入多进程/多 worker。
- 不承诺合盖/电池供电时 7×24 可用。

## 2. 拓扑

```text
iPhone / iPad / 家庭设备
   │ Tailscale 客户端登录同一 tailnet
   │ HTTPS（<machine>.<tailnet>.ts.net，Let's Encrypt 证书）
   ▼
Tailscale Serve（仅 tailnet 可达，终止 TLS）
   │ HTTP 到回环
   ▼
FastAPI 127.0.0.1:8000（已迁移；仅 Serve 可访问）
   │ 仅本机
   ▼
Ollama 127.0.0.1:11434
```

要点：

- Serve 从回环地址转发，应用只信任回环代理头；`FORWARDED_ALLOW_IPS` 禁止 `*`。
- Tailscale ACL 只约束 tailnet 流量，不保护局域网明文直连。
- Tailscale 身份头不能替代 Bearer Token；Serve 注入的头本机任意进程都可伪造。
- `ts.net` 主机名会进入公开 Certificate Transparency 日志，机器名不要使用个人信息。

## 3. 已确认的决定

| 决定 | 内容 |
|---|---|
| 接入方式 | Tailscale Serve；不启用 Funnel，不做端口映射/DMZ/UPnP（已确认） |
| 认证 | Bearer Token 保持不变；成员库哈希校验 |
| 成员粒度 | 默认“一人一 Token”；设备级撤销交给 Tailscale |
| 账号结构 | 家庭成员各自 Tailscale 账号，加入同一 tailnet（已确认） |
| 绑定地址 | 已确认改为 `127.0.0.1:8000`，使 Serve 成为唯一入口；过渡期暂不改 `.env` |
| 局域网保留 | 迁移后不再保留无 Tailscale 的局域网明文直连 |
| CLI | 不新增设备表、删除成员或 Web 管理页；沿用 create/list/rotate/revoke |
| 日志 | 关闭 uvicorn access log；应用日志只记 path，不记查询串、Token、正文 |

## 4. 阶段与状态

### V8.0 代理信任、日志隐私与接线硬化（已完成）

不依赖 Tailscale 账号，先消除两类真实风险：

1. 代理头信任原本依赖 uvicorn 默认值/环境变量，可能被放宽为 `*`。
2. uvicorn 默认访问日志会记录完整请求行，包括 `/api/v1/memory?query=...` 的自由文本；一旦由 LaunchAgent 落盘，会把记忆搜索内容写入磁盘。

已完成改动：

- `config.py`：新增 `forwarded_allow_ips`（默认 `127.0.0.1,::1`）与校验器；拒绝空值、`*`、非回环地址；提供 `forwarded_allow_ips_list`。
- `main.py`：`create_app()` 挂载应用级 `ProxyHeadersMiddleware`，两条启动路径都使用校验后的回环白名单。
- `__main__.py`：显式 `proxy_headers=False`、`access_log=False`；代理信任只由应用层负责。
- `.env.example`：新增 `FORWARDED_ALLOW_IPS` 注释与安全默认值。
- 测试：校验器、`__main__` 接线、回环/非回环/XFF 链、应用级中间件配置、查询串不落日志（含真实 uvicorn 子进程）。
- 结果：`uv run pytest -q` → **153 passed**；`uv run ruff check .` → **All checks passed**。
- 真实进程：重启 `python -m family_ai_api` 后，`/api/v1/health?query=...` 返回 200，终端不再出现访问日志行。

## 5. 验收标准（V8 完成定义）

- [ ] 仅 Tailscale Serve 提供 tailnet 内 HTTPS；未启用 Funnel；无端口映射/DMZ/UPnP。
- [ ] 代理信任仅回环；`FORWARDED_ALLOW_IPS` 为 `*` 时启动失败；非回环来源无法伪造 XFF。
- [ ] 查询串、Token、Authorization、聊天正文、任务/记忆内容不进入任何日志。
- [ ] tailnet 内 `https://<machine>.<tailnet>.ts.net/api/v1/health` 返回 200，证书受信任。
- [ ] 未加入 tailnet 的公网设备无法访问；ACL 负向测试设备被拒。
- [ ] 无 Token/错误 Token/已撤销 Token 均为 401；非 admin 为 403。
- [ ] 流式与非流式聊天、SSE done、限流与并发行为不回归。
- [ ] 局域网访问按绑定决策表现符合记录；若 opt-out 保留 `0.0.0.0`，残余风险已写入验收。
- [ ] Token 轮换/撤销即时生效；admin Token 轮换后 `.env` 明文已清空。
- [ ] `tailscale serve reset` + `tailscale down` 可回到 V7 形态。
- [ ] 真机 iPhone 通过 Tailscale 完成连接与聊天。

## 6. 回退

1. `tailscale serve reset`
2. `tailscale down`
3. 若已迁移绑定，把 `.env` 的 `APP_HOST` 改回 `0.0.0.0` 并重启。
4. 确认 `tailscale funnel status` 为 off。
5. 局域网健康检查与 iOS 局域网地址恢复。
6. 无需改代码或迁移数据库。

## 7. 已知限制与风险

- MacBook 睡眠/合盖后 Tailscale、FastAPI 与 Ollama 全部离线；无法跨三层 WoL 唤醒。外部访问需接电源 + 开盖。
- 依赖 Tailscale 控制面/中继；控制面可见设备与连接元数据；DERP 中继时可用性依赖第三方。
- 免费 Personal 仅限非商业用途；额度与控制台 UI 以官网当前页面为准。
- Serve 的 Host 头仍未测量；X-Forwarded-For 已实测为 tailnet 100.x（`/logs` client 字段）。在 Host 实测前不启用 `TrustedHostMiddleware`，按 IP 限流也暂不启用。
- 全局并发 2 由所有成员/设备共享，外部访问会增加 429 概率。
- 未认证路径暂无频率限制；日志仅内存 200 条，重启清空。
- Tailscale ACL 不保护局域网明文路径；若 opt-out 保留 `0.0.0.0`，Token 是唯一防线。
- iOS 同一时间只能启用一个 VPN；后台挂起与 On Demand 行为需真机验证。
