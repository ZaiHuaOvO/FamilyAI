## 1. 目标

在开始写业务代码之前，确认工具链完整、项目可复现、安全边界清楚：

- 基础工具（Xcode CLT、Git、VS Code、uv）可用。
- 用 `uv` 创建标准 Python 项目，依赖可锁定、可复现。
- 项目结构与目标结构一致。
- Git 仓库与 `.gitignore` 就位，密钥不会被提交。
- 文档库建立，后续阶段有据可查。

## 2. 环境检查清单

在“苹果菜单 → 关于本机”确认设备信息，并检查磁盘：

```bash
uname -m
sw_vers

```

要求：

- Apple Silicon（本机为 arm64）。
- 至少预留 20～30GB 可用空间（模型 + 依赖 + 日志）。
- 本机磁盘可用约 674GiB，满足要求。

### 3.1 安装 uv

官方安装命令：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

安装后重开 Terminal，或加载 shell 配置：

```bash
source "$HOME/.local/bin/env"
uv --version
```

本机安装器已把下面一行写入 `~/.zshrc`：

```bash
. "$HOME/.local/bin/env"
```

若 `uv --version` 找不到命令，先修复 PATH，不要继续堆叠后续步骤。

### 3.2 Ollama

Ollama 的安装与模型下载属于[阶段1](阶段1-本机运行模型.md)，避免在环境未验证时一次做完所有事情。

## 4. 创建项目

在仓库根目录执行：

```bash
uv init --app --python 3.12 --name family-ai-api
```

本机实际结果：

- 创建 `pyproject.toml`、`.python-version`、`README.md`、`src/family_ai_api/__init__.py`。
- 自动初始化 Git 仓库，默认分支 `main`。
- uv 下载并固定 Python 3.12.15。

安装依赖：

```bash
uv add "fastapi[standard]" httpx pydantic-settings
uv add --dev pytest pytest-asyncio ruff
```

生成并提交 `uv.lock`，保证在其他设备可以恢复相同依赖版本。

> 注意：`uv init` 会在项目为空时写入占位 `README.md` 和 `[project.scripts]`。本项目已删除无对应函数的 `family-ai-api = "family_ai_api:main"` 入口，避免安装后出现无效命令。
