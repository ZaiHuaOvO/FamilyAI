# V4：家庭任务与提醒

> 状态：**已完成（2026-10-18）**  
> 前置：V3（`v3.0.0`）已完成  
> 决策依据：[V4 家庭任务与提醒方案决策](../06-决策记录/V4-家庭任务与提醒方案.md)

## 1. 目标与决定

帮助家庭记录任务、查看今日/逾期事项，并在需要时查看简报。

已确认的决定：

- 范围：**本地任务 + 可选天气**。
- 通知：**仅 API/页面**，不做主动推送。
- 简报：**手动查看**，不引入定时调度。
- 不读取 Apple 日历，不发邮件。

## 2. 架构

```text
任务 API / 页面
    ↓
SQLite data/tasks.db（标题、备注、到期、完成状态）

简报：
open 任务 → 今日到期 + 逾期 → 可选 Open-Meteo 天气 → 返回 / 页面展示
```

天气仅在配置 `WEATHER_LATITUDE` / `WEATHER_LONGITUDE` 时启用；天气失败不影响任务简报。

## 3. 代码模块

| 文件 | 职责 |
|---|---|
| `tasks/store.py` | SQLite 任务 CRUD、到期筛选、完成状态 |
| `tasks/service.py` | 校验、今日/逾期简报、天气汇总 |
| `tasks/weather.py` | Open-Meteo 请求与 WMO 天气码映射 |
| `routers/tasks.py` | 任务 CRUD、简报、管理页面 |
| `main.py` | 挂载任务路由 |

## 5. 接口

| 方法 | 路径 | 说明 | 认证 |
|---|---|---|---|
| `POST` | `/api/v1/tasks` | 新建任务 | 是 |
| `GET` | `/api/v1/tasks` | 列表/筛选 | 是 |
| `PATCH` | `/api/v1/tasks/{id}` | 修改/完成/清空到期 | 是 |
| `DELETE` | `/api/v1/tasks/{id}` | 删除 | 是 |
| `GET` | `/api/v1/tasks/view` | 任务管理页面 | 页面可访问，数据需 Token |
| `GET` | `/api/v1/briefing` | 今日/逾期简报 + 可选天气 | 是 |

筛选参数：

- `status=all|open|done`（默认 `all`）
- `due=all|today|overdue`（默认 `all`）
- `today`：到期日期等于本地今天；`overdue`：到期日期早于今天（避免与今日重复）。

## 6. 安全与隐私

- 任务数据保存在 `data/tasks.db`，已被 `.gitignore` 忽略。
- 所有任务数据接口需要 Token；页面不嵌入数据，Token 只保存在页面内存。
- 日志只记录路径、状态与耗时；不记录任务标题、备注或简报内容。
- 不读取日历、邮件或通讯录；不主动推送通知。
- 天气请求只发送经纬度到 Open-Meteo；不发送任务内容。
- 天气请求可能使用系统代理；天气失败不会影响任务功能。

## 8. 已知限制

- 没有主动通知；需要用户打开页面或调用 API。
- 不支持 Apple 日历、邮件或手机推送。
- 天气需要配置经纬度，并依赖外部网络；天气不可用时简报仍正常返回任务。
- 不支持重复任务、子任务、提醒时间或按成员分配。
- 任务页面只能通过 API 修改到期时间；页面上可编辑标题、完成状态与删除。
- `due_at` 支持带时区或本地时间的 ISO 8601；无时区值按本机时区解释。
