## 已知限制

- MacBook 合盖/睡眠会中断服务；长期运行需保持开盖并连接电源。
- 锁屏与显示器关闭未单独测试，部署方式不依赖该场景。
- Mac 的局域网 IP 可能随 DHCP 变化。
- 限流与并发状态仅保存在单进程内存中。
- 系统 swap 在并发测试后约 6.0GB，需持续观察。
- 请求日志只保存在内存中，进程重启清空；`/chat/stream` 的访问日志耗时是响应头时间，真实耗时见 `done` 事件。
- 对话历史由客户端携带，服务端不持久化。
- 知识库只索引 MD/TXT；真实资料目录与索引数据库不提交 Git。
- RAG 查询实测约 7.3～7.5s；聊天与 Embedding 同时加载约 5.5GB，需观察 swap。
- 自动记忆提取会为每次聊天增加一次后台模型调用，可用 `AUTO_MEMORY_ENABLED=false` 关闭。
- V3 记忆为全家共享；更换 Embedding 模型后需要重新生成记忆向量。
- 任务与简报仅手动查看，无主动通知；天气需配置经纬度并依赖外部网络。
- Agent 规划依赖本地模型，可能选错工具；pending action 与审计在内存中，重启清空。
- Embedding 与聊天模型同时加载会增加内存占用，需观察 swap。
- 本文档记录的是当前真实状态；每次阶段验收后必须同步更新。
